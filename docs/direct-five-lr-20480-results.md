# 三色囲碁AI・学習率5条件 × 累計20,480局：実測結果

GitHub Actions [run #41269768815](https://github.com/nao70161994/three-color-go/actions/runs/41269768815) は5条件の学習・全32個の追加チェックポイントでのCPU評価・未使用seedの独立評価・5条件比較を**すべて成功**した。2026-11-01。

## 試験条件
学習率 `0.001 / 0.0003 / 0.0001 / 0.00003 / 0.00001`、各モデル累計20,480局。先行する10,240局モデルの重み・Adam・乱数状態から**さらに10,240局／モデル**追加学習（5条件で追加51,200局）。

学習は自己対戦（3色で同一モデル）、報酬は終局残石数割合のみ、教師棋譜・探索・MCTSなし。学習盤面半径2/3/4。途中評価は320局刻み全64地点、固定CPU4構成×盤面半径3/4×各12対戦。最終モデルは途中評価とは異なる新seedで、各192対戦。

## 最終モデルの独立CPU評価（20,480局）

| 学習率 | 平均最終石数割合 | 勝利配分率 | 「難しい＋バランス」相手の石数割合 |
|---:|---:|---:|---:|
| **0.001** | **53.18%** | **61.46%** | **46.18%** |
| 0.0003 | 28.58% | 32.29% | 15.18% |
| 0.0001 | 14.23% | 13.54% | 6.55% |
| 0.00003 | 5.56% | 1.04% | 5.96% |
| 0.00001 | 2.65% | 0.00% | 3.86% |

勝利配分率は同率1位の場合に勝利を分割する指標。単独勝率そのものではない。最良は**学習率0.001**。

## 同じ固定CPU評価seedによる途中評価の変化

| 学習率 | 10,240局 | 20,480局 | 過去64地点の最高 | 最高地点 |
|---:|---:|---:|---:|---:|
| 0.001 | 34.87% | **54.82%** | **59.88%** | 19,200局 |
| 0.0003 | 25.68% | 31.90% | 40.24% | 9,600局 |
| 0.0001 | 8.73% | 9.04% | 19.31% | 17,600局 |
| 0.00003 | 3.60% | 8.71% | 8.71% | 20,480局 |
| 0.00001 | 2.51% | 3.67% | 5.96% | 19,840局 |

この**途中評価の差**は同じ相手と評価seedで比較したもの。一方で10,240局時点の最終モデル独立評価と20,480局時点の独立評価ではseedが異なるため、独立評価数値を直接引き算して改善量としない。

### 解釈と課題
1. 学習率0.001は20,480局時点まで大きく改善。別seedの最終評価でも5モデル中最良であり、低学習率ほど長期的に強いという仮説は現時点では支持されない。
2. 学習率0.0003も伸びるが、20,480局時点の最終独立評価では0.001に大差。0.0001の17,600局モデルなどには一時的なピークがある。
3. **途中最大値は固定seedを64回使った最大値**なので選択バイアスがある。0.001の19,200局モデルを20,480局モデルより強いと判断するには、チェックポイントを新しい複数seedで対決させる必要がある。
4. 対戦相手と盤面サイズが限定的（半径3/4）。本番の半径8〜12への一般化は未検証。学習の収束も不明。複数の学習初期seedによる再現性検証が必要。
5. **本番サイト・既存CPUは未変更**。新モデルの即時採用はしない。

# パス込み追加学習後の5モデル：独立3人対局ベンチマーク

102,400局の元重みから各20,000局追加（累計122,400局）。合法着手とパスを同じネットワークで直接評価。
学習未使用seed：CPU比較 20471103/20471104、AI同士 20471203/20471204。半径3/4。
CPU比較：各モデル384局（4種のCPU組×2盤面×各48局）。全5モデルで1,920局。
モデル同士：10組×2盤面×第三CPU hard/balanced×48局＝1,920局。6座席ローテーション。

**重要：3人連続パスで自然に終局しない場合、盤面マス数×3＋3手で観測を打ち切り、勝敗を付けない。**
以下の「観測石数割合」と「石数多」は、未終局の途中盤面も含み、最終勝率ではない。

## 結論と解釈

- **0.0003と0.001はほぼ同率の上位2モデル。** 既存CPU比較の観測石数割合は79.86%／79.80%で、差はわずか0.06ポイント。
- 上位2モデルの直接対戦192局はすべて自然終局。0.001側97局対83局（同石12局）だが、石数割合差は -0.74pt、95%区間 [-5.53, +3.78]pt で明確な優位はない。硬い相手（hard＋balanced）では0.001が68.01%、0.0003が62.53%で、組み合わせによって評価が変わる。
- **0.0001は中位**。対既存CPUの観測石数割合50.34%、自然終局378/384。上位2モデルには直接対戦で明確に劣る。
- **0.00003と0.00001は下位**。対既存CPUで42.94%／24.24%だが、両者同士の直接対戦192局で自然終局は16局のみ。比較の大部分が途中局面のため、この2モデル間の優劣は未確定。
- 全5モデルについて自然終局できない試合が存在。完走率と戦略的なパス判断にまだ改善余地がある。
- この検証は**公開モデルの変更や追加学習を行っていない**。まだサイト内のモデルを置換していない。

## 検証の実施と再現性

- 実行: [GitHub Actions run #41580142194](https://github.com/nao70161994/three-color-go/actions/runs/41580142194)、全17ジョブ成功。集計JSON/Markdownは `pass-five-strength-results`、個別の評価成果物は `passcpu-*` / `passduel-*`。
- モデル元: [パス学習 run #41487742023](https://github.com/nao70161994/three-color-go/actions/runs/41487742023)。各モデルについて元の102,400局から追加20,000局（パスを含む）で、重みの変換・追加更新なし。学習率は0.001 / 0.0003 / 0.0001 / 0.00003 / 0.00001。
- 評価エンジン: `scripts/benchmark-direct-matchups.mjs` / `scripts/benchmark-direct-headtohead.mjs` / `scripts/compare-direct-strength.mjs`。
- 各対局で6色順をローテーションし、固定した新規評価seedを用いた。ニューラルモデルは最大確率行動（greedy）を選び、合法着手とパスを同一の行動集合で比較。自己眼などの戦略的ルールによる禁止は**なし**。
- 3人連続パスの自然終局がなければ、盤面マス数の3倍＋3手の上限で打ち切り。**強制パスは実行せず、打ち切った試合に勝敗を割り当てない**。観測石数割合はその時点の石数にもとづく指標であり、自然終局した試合の勝率と混同しない。
- ブートストラップ95%区間は探索的な指標。第三プレイヤーの強さ、盤面半径、擬似乱数seedに依存する。今後は未使用seedの追加検証、半径5以上の一般化、終局できない局面の原因分析が必要。

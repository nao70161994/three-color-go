# 強い学習済みCPUを3種類採用

過去の学習済みモデルも含む6,564局の相互対戦の結果を踏まえ、単独の「最強モデル」に決めつけず上位3種類を選択式に採用する。

- 新AI：Attention 64次元／50,000局：elite-attn64-50000
- 新AI：64次元GNN／50,000局：elite-gnn64-50000
- 旧PV2：学習率0.001／累計122,400局：elite-pv2-122400

3つの候補は第2段階の別乱数評価で近接しており、最強が確定したわけではない。旧PV2は元の102,400局からパス込み20,000局の追加学習モデルを採用。以前のサイト組込版（102,840局）とは別物。

## 操作

「CPUの強さ」の3項目として追加。既存難易度、旧学習済みモデルは削除しない。

「自由編成」では黒・白・赤それぞれに別モデルを割り当てられる。AI三者を同時に選択すると対戦を観戦でき、1手進める、一時停止、棋譜保存と復元にも対応。オンラインの人間対戦には介入しない。

メイン／Web Worker／オフライン単一HTMLのいずれも同じ元の重みを利用。モデルの棋力を強化するルール補正や強制パスは一切追加しない。純粋な合法着手＋パスを選ぶ方策（greedy）。

## 真正性

- Attention とGNN64の50,000局チェックポイント：GitHub Actions run 41672945203、各 architecture-milestone-6250-* のmodel.json。
- 旧PV2のパス20,000局モデル：run 41487742023、pass-20k-lr001 内の pass-20k-lr001.json。
- scripts/generate-elite-assets.mjs が元のメタデータを厳格検証して src/elite-model-data.js を生成する。sha256は src/elite-model-provenance.json に保存。
- モデル重み自体は変更も追加学習もしない。

学習時に用いた盤面半径2/3/4より大きな盤面にも推論自体は可能だが、実際の棋力は未検証。特にAttentionは盤面全体の計算を行うため、広い盤面では手の選択が遅くなる可能性がある。

ブラウザー表示とオフライン版は同じ上位3モデルを使用し、旧PV2と新GNNの関数名が衝突しないよう単一HTML化時にモジュールスコープを分離する。

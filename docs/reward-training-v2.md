# 新しい自己対戦報酬：石数割合 − 安全上限ペナルティ

**これは既存の公開モデルとは独立した実験用の新規学習経路です。**

## 報酬の定義

各プレイヤー `i` について：

`reward_i = stone_count_i / total_stone_count - (truncated ? timeout_penalty : 0)`

3人の石数合計が0なら基本石数割合は3人とも1/3。
自然終局（3人連続パス）ではペナルティ0、安全上限に到達した未終局局では全員に同じペナルティ（既定0.3）を適用する。**未終局の盤面は「最終盤面」ではなく上限時点の観測盤面**として扱う。

- 自然終局・黒20白10赤5: 報酬 `[0.57143, 0.28571, 0.14286]` （合計1）
- 上限到達・黒20白10赤5・penalty0.3: `[0.27143, -0.01429, -0.15714]` （合計0.1）
- 自然終局・黒白赤0: `[1/3,1/3,1/3]`

ペナルティは **0.3を初期仮説**として採用。最適値と証明された数値ではない。将来0,0.1,0.3,0.5,1などを別学習で比較する。

## 戦略への人為的介入は行わない

- 着手とパスは最初の一手から常に合法行動として同時に評価される
- パス専用のマイナス初期バイアスは一切付けない。新規ランダム初期化から開始する
- 眼埋め禁止、序盤パス禁止、手数によるパス強制、探索、教師の着手ラベルを使用しない
- 学習の行動選択は softmax(方策値 / temperature) からの確率サンプリング
- 1反復では3人が同一の固定モデルを使い、全3人の実着手を集めて更新する
- 安全上限（既定 `100 × 盤面マス数 + 3`）は安全装置であって終局ルールではない。打ち切りを `ended=false,truncated=true` と明記する
- 連続パス数の新しい入力や過去モデルとの対戦は本変更の範囲外（今後の比較実験対象）

## Value損失と既存モデルとの互換性

新モデルのメタデータ `valueOutput: "independent"` なら Value の3出力を制約のない実数で解釈する。従来のPV2モデルは従来通りsoftmax（合計1）を使う。この識別によって既存CPUの推論・重みは変わらない。

- 方策勾配：`-(R_self - stop_gradient(V_self)) × log π(action)`
- Value：`MSE(V, [R_self,R_next,R_other])`
- Entropy：`-entropy_coefficient × H(π)`
- 更新：Adam、勾配最大ノルム2
- 終局結果だけでなく、打ち切り時の観測石数と減点も学習する。これが「打ち切り報酬」による学習であり、本来の将来価値と一致する保証はない

## 実行例

```bash
python scripts/train-direct-reward.py \
  --iterations 10 --games 8 --radii 2,3,4 \
  --temperature 1.5 --learning-rate 0.001 \
  --entropy 0.015 --batch-size 32 --epochs 1 \
  --horizon-multiplier 100 --timeout-penalty 0.3 \
  --checkpoint-every 5 --seed 20261103 \
  --out reports/reward-new.json
python scripts/check-pv2-parity.py reports/reward-new.json
```

`--resume` は同じ引数のチェックポイントを使用。最新のモデルに直接手動のパス・バイアスを与える機能や、旧モデルからの初期化機能はこの新学習経路には存在しない。

## リスク・評価基準

報酬ペナルティだけでは全員が開始直後にパスして同率1/3になる均衡を完全には防止できない。自然終局率、上限到達率、早期3人パス率、石数割合、勝率を別々に評価すること。安全上限に達した試合の観測石数割合も真の終局時の価値ではなく、意図的に加えた代理報酬である。最適化される目的がゲーム本来の勝率からずれる可能性に注意する。

既存の `scripts/train-direct-policy.py` は**過去モデルを再現するレガシー学習機構**として維持する。新モデルの学習では `scripts/train-direct-reward.py` を使う。

## 進行度を削除したモデル形状

2026-11-03以降、新規報酬学習経路は別形式 `hex-group-pv-16-v3-no-phase` を利用する。
各マスの入力は11→10特徴量になり、`moveCount` から作る進行度の入力を完全に削除。Embeddingは `Linear(10,16)+ReLU`、六角隣接の平均を利用するメッセージパッシングは従来どおり3層16次元、方策出力は盤面全マス+パス、Valueは3つの独立実数のまま。

特徴量の内訳は「自分/相手2人/空点の4ビット」「色ごとの呼吸点の3値」「色ごとのグループサイズの3値」で合計10。値の基準と石の座標は従来維持する。

旧 `hex-group-pv-16-v2` チェックポイントは既存の11特徴量を維持し、推論動作を変更しない。新モデルは入力層が異なるため旧モデル重みの流用は行わず、常に最初から学習する。`direct-reward-actor-critic-resume-v2-no-phase` をチェックポイント形式として、旧形式からの誤った継続を防ぐ。

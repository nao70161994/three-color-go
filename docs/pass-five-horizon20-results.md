# パス判断に関する検証の再評価：手数上限を20倍の盤面マス数へ延長

## 結論

2026年11月3日、追加学習20,000局×5モデル（各累計122,400局）について、旧検証と**同一の5モデル・同一seed・同一CPU相手・同一座席ローテーション**で3,840局を再実行しました。唯一の重要な評価条件変更は、打ち切り上限を盤面マス数×3＋3手から、**盤面マス数×20＋3手**に延ばしたことです。

**旧評価で「未終局」と記録した496局のうち、379局（76.41%）は旧上限の後に自然終局しました。** 旧評価でそれらを「パス判断が悪いから終局できない」とみなすのは誤りでした。

| 項目 | 旧上限（×3＋3） | 新上限（×20＋3） |
|---|---:|---:|
| 半径3（37マス） | 114手 | 743手 |
| 半径4（61マス） | 186手 | 1,223手 |
| 評価総数 | 3,840局 | 3,840局 |
| 3人連続パスによる自然終局 | 3,344局 | **3,723局** |
| 打ち切り（勝者なし） | 496局 | **117局** |
| 旧上限後に新たに自然終局 | — | **379局** |

上限は実行時間・計算量を制御する安全措置であり、ゲームのルールやAIの着手・パス判断には組み込まれていません。残る117局も「勝敗不明」であって、永久に終局しないと証明されたものではありません。

## 方法上の注意

- 学習した行動集合にはパスを含む。推論は合法手＋パスの最大確率選択（greedy）。MCTS・探索・眼埋め禁止などの戦略ルールは追加していません。
- **自然終局**は、3人が連続してパスした場合のみ。安全上限を超えたら強制パスは行わず、打ち切り局として分類します。
- 長い試合が必ず悪いわけではありません。「パスが妥当か」を証明するには、最終結果に加え、無意味な早期パスや勝敗への影響も別途評価すべきです。
- 20倍という上限自体も理論的な最適値ではありません。**自然終局した局の最長は半径4で1,174手（安全上限1,223手）**と、なお上限に近い例がありました。延長してなお117局が打ち切りのため、とくに下位2モデルについては50倍／100倍等の感度検証が望まれます。
- 盤面半径3・4の評価であり、半径5以上への一般化や人間に対する強さは未検証。
- 公開モデルの重み・本番サイトは変更していません。

# 学習率5条件の継続学習：2,560局→5,120局の実測結果

2026-11-01、[GitHub Actions 実験 #41227525978](https://github.com/nao70161994/three-color-go/actions/runs/41227525978) は **5学習率すべての追加学習・途中評価・独立最終評価・比較集計が成功**。

- PR #25。公開CPUは変更していません。
- 以前の2,560局モデルから**重み・Adam・乱数状態を引き継ぎ**、各モデルを5,120局まで延長。学習率 **0.001、0.0003、0.0001、0.00003、0.00001**。
- 3人の同一ネット共有、**教師棋譜なし・探索なし・最終盤面に残った石数割合を報酬**。半径2・3・4で学習。
- 320局ごとの16チェックポイントで半径3/4・4組の既存CPU（hard+balanced、balanced+balanced、tactical+guarded、baseline+baseline）と対戦。最終モデルは評価に未使用の**別シード、各学習率192局**で評価。
- すべての率で学習中の終局残存石数・捕獲石数・被捕獲石数もログに保存。

## 結果：5,120局の最終モデル（独立シード）

| 学習率 | 平均最終石数割合 | 勝利配分率 | 難しい＋バランス相手の平均石数割合 |
|---:|---:|---:|---:|
| **0.001** | **30.75%** | **35.42%** | **13.69%** |
| 0.0003 | 17.86% | 17.45% | 4.92% |
| 0.0001 | 3.57% | 0.00% | 4.98% |
| 0.00003 | 2.55% | 0.00% | 4.36% |
| 0.00001 | 6.52% | 1.56% | 4.89% |

勝利配分率は同率1位を分割した値。**全対戦相手の平均で0.001が最良**。ただし「難しい＋バランス」に限定すると13.69%なので、強い既存CPUを安定して倒す実力を示したわけではありません。

### 捕獲石数の注意点

半径2/3/4の混在自己対戦で、全3色合計の平均捕獲数は0.001では前半 **46.70**、後半 **47.11**。この微増だけでは強さを判断できない。自己対戦では対戦相手も同時に強くなるため、**固定CPUへの評価を主指標**とする。

## 次の課題

1. **学習を一律5,120局で完了とみなさない**：特に0.001は最後の評価地点でも上昇中。さらに長くする場合はチェックポイントごとの固定CPU評価・独立シードで確認し、Adam状態から引き継ぐ。
2. 0.001の最良モデルでも強CPU相手には低い石数割合。通常CPUの代替候補とする前に強い相手に対する勝率・座席別のばらつきを追跡。
3. **学習半径2/3/4、評価半径3/4**であり、ユーザーが想定する半径8〜12で強いという証拠ではない。大盤面の性能測定と学習対象拡張が必要。
4. 学習初期シードは1つ、評価は半径・相手構成ごとに各24局。ここでの優劣はこの実験条件に限る。複数学習シードなどで検証するとより信頼できる。

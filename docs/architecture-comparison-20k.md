# 三色囲碁 深層学習モデル構造比較（各20,000局）

## 仮説
- gnn16：10特徴量→16次元→近傍情報交換3層（現行方式と同形状）
- gnn64：10特徴量→64次元→近傍情報交換3層（次元数のみ拡大）
- attn64：gnn64＋全盤面Attention2層、各4ヘッド・学習可能な六角距離バイアス

3モデルとも同じ報酬（観測石数割合−上限打ち切り時0.3）、パス自由、自然終局に人為的介入なし、進行度削除。ネットワークの重みは新規ランダム初期化。先読み・教師手のラベルなし。

## 20,000局の手順
architecture-comparison-20k.yml で各モデル20,000局＝8局×2,500反復を学習。GitHub ActionsのCPU runnerで、3モデルを並列学習し、各2,000局で区切ってoptimizer/RNG checkpoint（.pt）から厳密に再開する。ひとつの段階を完走した場合だけ次へ進むため、実行時間制限を越える場合には途中までの達成として扱い、完了を偽らない。

- 学習盤面：半径2,3,4を反復ごとローテーション
- 乱数：20261103、自己対戦では1モデルを3人全員に使用
- 進行度：無し（10特徴量）
- temperature：1.5、Adam LR：0.001、entropy：0.015、batch：32
- 安全上限：マス数×100＋3手、強制パスはしない
- トレーニングメモリ節約のため、各対局の方策勾配サンプルは4手ごとに選択（開始オフセットはseedから決定）。実際の対局の行動選択・報酬は全手について実行される。これは従来の「全手を学習に使う」とは異なる共通設定
- 2,000/4,000/.../20,000局でモデルJSON、optimizer、各段階の学習logを保存
- 各途中評価は半径3/4で各18局、balanced+tactical CPU相手。全モデル共通の座席循環・評価seed、20×評価上限、未終局は勝者として数えない
- 完了後60件（3モデル×10地点×2盤面）の中間評価をCSV/Markdownに統合

**注意：** 学習中の安全上限100×は、自然終局しない対局を「終局したもの」と偽るためではなく、観測石数から共通の負の報酬を与える訓練上の選択。ペナルティ0.3は仮説値であって最適と確定した数値ではない。

全盤面Attentionは近傍GNNの後に配置し、各マス同士の関係を重み付き平均する。六角相対距離によるバイアスも初期値ゼロから学習させる（距離に応じた戦略ルールは設定しない）。

比較学習用の全モデルは候補のみで、公開中のCPUや既存チェックポイントを変更しない。学習の経過はGitHub Actionsのログと成果物を参照する。

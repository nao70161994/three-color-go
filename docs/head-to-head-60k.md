# 三色囲碁AI・30地点の直接対戦比較

3モデルの保存済みチェックポイント（学習2,000局から60,000局まで2,000局間隔）を新たに学習せず、実際に相互対戦させる。

- gnn16、gnn64、attn64 の三者同時対戦：六つの全席順×2乱数反復、半径3・4。
- 三組の2モデル比較：AABとABBの二構成、単独席を黒・白・赤に交代、同じく2乱数反復。モデルが2席を占めるための見かけの勝利増加は、1席あたりの勝利配分率に直して補正する。
- 確率方策はtemperature=1.0。貪欲方策は各盤面につき六つの席順を一度ずつのみ評価。
- パスは開始から合法。強制パスなし。安全上限で終わらなかったゲームは勝敗不明扱い。
- 石数で勝敗を決定し、同率勝利は按分。盤面半径3・4はともに検査。
- モデルはGitHub Actions run 41610283160（2千～2万）、run 41672945203（2.2万～6万）から正しい学習局数のmodel.jsonを復元する。
- 同じ乱数系列とすべての席順を使い比較するが、近接するチェックポイントは独立したサンプルではなく、学習seedも構造ごとに一つだけ。小さい勝率差は過信しない。
- 評価は学習から独立で、重みや公開CPUを変更しない。

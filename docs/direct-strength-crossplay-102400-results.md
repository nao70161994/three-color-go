# 三色囲碁AI：どの学習モデルが本当に強いか（独立評価＋直接対戦）

[実験のGitHub Actions run #41409728999](https://github.com/nao70161994/three-color-go/actions/runs/41409728999) · [総当たり評価JSON/Markdown artifact](https://github.com/nao70161994/three-color-go/actions/runs/41409728999/artifacts/13124559237)

## 結論

**現時点では学習率0.001が最有力。** 最終モデル（102,400局）と95,680局時点のモデルは、どちらも未使用seedのCPU評価で約59%の残石割合を記録し、両モデルの直接対戦で決定的な差は確認されなかった。**0.0003は最新モデルより95,360局の途中モデルのほうが強かった**ため、最新重みだけを一律に採用するのは適切でない。

評価は9候補×384局＝**3,456局**の独立CPU対戦、15組×192局＝**2,880局**のAI対AI直接対戦、**合計6,336局**。新しい評価seedと色・座席6通りのローテーションを使用。5つの最新モデルと、以前の定点評価が高かった4つの途中checkpointを別々に評価した。

最新5モデル総当たりでは0.001最新が、0.0003・0.0001・0.00003・0.00001それぞれの最新モデルより平均石数割合差で優勢だった。0.0003最新も低3学習率に優勢だった。

## ③ 解釈：どのモデルを採用すべきか

- **強さ重視なら第一候補は0.001の102,400局版**。新しいCPU評価が首位で、0.0003最新との直接対戦にも優勢。
- **0.001の95,680局版を同等有力候補として保持**。直接対戦では最新版との差は不明確。途中のピーク版が最新より強いと断言する根拠もない。
- **0.0003の95,360局版は、102,400局版より有力**。直接対戦で平均石数割合+16.24ポイント相当の優位（最新の視点では-16.24ポイント）を示した。
- **0.001最新対0.0003途中ピークはまだ決定的でない**。4種類の第三CPU・新しい学習seed・より大きい盤面で再検証する価値がある。
- 0.0001、0.00003、0.00001は主力候補としては劣るが、戦略多様性のために全て保存してよい。「強い」と「異なる戦略を実際に選ぶ」は別問題であり、購入傾向の分化をここでは検証していない。

## 検証の限界

この結果は**半径3/4のみ**、greedy探索なしニューラル方策、第三プレイヤーがCPU（hardまたはbalanced）の直接対戦に限定される。半径8〜12の実用盤面、ほかの学習seed、3モデル全て学習AIでの直接対戦は未検証。強さの「完全確定」ではない。公開サイト・既存CPUの重みは更新していない。

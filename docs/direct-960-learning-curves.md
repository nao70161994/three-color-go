# 960局学習：石数・捕獲数の学習曲線と固定CPUとの対戦結果

- [全学習ログ・6時点のモデル重み・評価JSON（GitHub Actions）](https://github.com/nao70161994/three-color-go/actions/runs/41221126368)
- 2026-11-01の実測結果。全ジョブ成功、成果物 `direct-960-learning-curves` を保存済み。
- 公開CPU・サイトは変更していない。PR #23 はドラフトのまま。

## 条件

学習率 **0.0001**、Adam、バッチ32、1エポック、entropy係数0.015、1反復8局×120反復＝960局。全3席が1つのモデルを共有、終局時の残存石数割合が唯一の報酬。**教師・MCTS・先読みなし。**学習は半径2・3・4を順番に巡回。

160 / 320 / 480 / 640 / 800 / 960局時点でモデルを保存し、それぞれ半径3と4について、`hard+balanced`、`baseline+baseline`と、6局（全6座席順）ずつ対戦。1チェックポイント24局、全144局。

## 強さの実測：どのチェックポイントでも勝利配分0

| 累計学習局数 | 半径3 難しい+バランス 石数割合 | 半径4 難しい+バランス 石数割合 | 半径3 基本型+基本型 | 半径4 基本型+基本型 | 24局の勝利配分 |
|---:|---:|---:|---:|---:|---:|
| 160 | 4.43% | 2.78% | 2.26% | 0.00% | 0 |
| 320 | 1.15% | 4.40% | 7.07% | 0.00% | 0 |
| 480 | 5.08% | 4.83% | 2.15% | 1.39% | 0 |
| 640 | 9.93% | 3.72% | 3.33% | 0.00% | 0 |
| 800 | 8.34% | 6.45% | 1.28% | 0.00% | 0 |
| 960 | 5.68% | 3.47% | 0.00% | 0.00% | 0 |

- **960局時点は最高成績ではない。** 難しい+バランス相手に半径3で9.93%→5.68%、半径4で6.45%→3.47%へ低下。
- 石数割合が低く、全144局で勝利配分ゼロ。ただし**各相手・半径・途中モデルにつき6局**なので、高い確度で収束の有無を結論づけられない。
- 6局すべてに1回ずつ座席ローテーションを適用したため、各色ごとの戦績はまだサンプル数が少ない。
- この測定は「計算回数を2倍にしたら強くなる」という期待を支持しないが、**960局での完全収束も証明しない**。

## 自己対戦中の残存石・捕獲石の推移

各半径について、最初の5反復・最後の5反復を比較。各反復8局、40局ずつの比較。

| 盤面半径 | 平均残石数の合計 初期→後期 | 平均捕獲石数の合計 初期→後期 |
|---:|---:|---:|
| 2 | 14.325 → 14.425 | 23.125 → 23.350 |
| 3 | 29.000 → 29.825 | 44.600 → 43.800 |
| 4 | 48.875 → 49.850 | 72.825 → 72.150 |

同じ強さの3人が同じニューラルネットで競い合う学習では、3色の石数割合の平均は常に **33.3%** になるため、平均石数割合の上昇による上達判定は原理的にできない。絶対残存石数・捕獲数も対戦相手の強さが同時に変わるので棋力を単独で証明しない。**固定CPU相手のチェックポイント評価が重要**。

## 判断と次の選択肢

- 学習率を下げて960局まで続けても、少なくとも今回の試行では一貫した棋力改善を認めなかった。480局が十分だったかどうかも、960局が十分かどうかも、この実験だけでは断定できない。
- 次の有力な調査対象は **ゲームで採用されるルール・合法手/パス/終局条件、特徴量の正規化と席順の影響、方策から貪欲選択する評価の偏り、自己対戦の多様性と更新のオフポリシー化、価値学習信号と報酬の分散**。今までの規模で勝てない問題を切り分けてから、半径8～12に広げる。
- 長時間学習を再開する場合は、学習時間固定で終えるのではなく、固定相手への成績と独立シードを複数使った信頼区間で改善が続くか判断する。改善がない場合にはアルゴリズムそのものの見直しを優先する。

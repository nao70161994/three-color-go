# 三色六角碁 (Three Color Hex Go)

3人で遊ぶ、六角形の盤を使った変則囲碁の試作です。**陣地ではなく「終局時に盤上に残っている石の数」だけを得点**とします。

> 現在はルールの妥当性を確かめるための **v0.1 プロトタイプ**です。既存の三色囲碁の公式ルールを主張するものではなく、本プロジェクト独自のルール案です。

## 遊び方

- `index.html` をローカルHTTPサーバーで開きます。
- 例： `python3 -m http.server 8000` → <http://localhost:8000/>
- 1台の端末を3人で交代して操作します（オンライン対戦・CPU対戦は未対応）。
- スマホブラウザにも対応しています。

## ルール v0.1

| 項目 | 内容 |
| --- | --- |
| プレイヤー | 3人（黒・白・赤） |
| 盤面 | 正六角形。六角マスの中心に置き、上下左右ではなく**6方向**で接続する |
| サイズ | 半径4、合計61点（後から変更可能） |
| 順番 | 黒→白→赤の順に1手ずつ。各自パス可 |
| 石の連結 | 隣り合う**同色**の石だけが連結する |
| 石を取る | 石の集団の呼吸点（隣接する空点）が0になったら、その集団を盤上から除去する。2色が共同で囲んでもよい |
| 自殺手 | 禁止。ただし着手時に相手を取って呼吸点ができる場合は可能 |
| コウ | 着手後の盤面が過去の盤面と同一になる手は禁止（全局同形禁止）。パスは例外 |
| 終局 | 3人が連続でパスしたら終了 |
| 得点 | **最後に盤上に残っている自分の石の数**（1石＝1点） |
| 勝敗 | 最大得点のプレイヤーが勝利、同点なら引き分け |
| 陣地・コミ・アゲハマ | 加点しない |

## 意図と検証したいこと

- 三色対戦で「白と赤が黒を協力して取る」ような攻防が成立するか。
- 石数だけの採点により、盤面を安全に埋めるだけの単調なゲームにならないか。
- 六角格子（6呼吸点）における生き死に、二眼、先手有利、パスのタイミングをプレイテストで確認する。
- 3人の談合やキングメーカー問題など、多人数戦特有のバランスを観察する。

## 未実装・注意点

- プレイヤーによる死に石の合意処理／終局後の自動死に石除去はありません。石数得点のため盤上の死に石も終局時には数えられます。取り除きたい石は終局前に実際に取る必要があります。
- CPU、ネットワーク対戦、セーブ・リプレイ、棋譜保存は未対応。
- UX向上のため「一手戻す」があります（対局中の相談や競技的な使用では禁止にするなど運用を決めてください）。

## 開発

依存パッケージなし。Vanilla JavaScript + HTML + CSS。ゲームロジックと表示を分離しています。

```sh
npm test
python3 -m http.server 8000
```
